# Integrations and webhooks

Plans never reach the network directly. They use **integrations**: declared, typed operations the runtime executes.

## Declaring an integration

```ts
const payments = a.integration("payments", {
  provider: "stripe",
  config: { secret: "STRIPE_SECRET_KEY" },          // names of secrets, never values
  operations: {
    charge: {
      mode: "call",                                 // returns data during the plan
      input: { orderId: t.id(), amountCents: t.int().min(1) },
      output: { chargeId: t.string().max(100) },
    },
    refund: { mode: "effect", input: { chargeId: t.string().max(100) } },  // sent after commit
  },
});

const charge = payments.call("charge", { orderId, amountCents: 2500 });   // charge.chargeId
payments.send("refund", { chargeId });
```

- **`call`** runs during the plan, and its output is validated against `output`. Calls are journaled: a re-run after a conflict reuses the result. A route can make at most 3 calls.
- **`effect`** is fire-and-forget, delivered through the outbox after commit, with retries.

## Receiving webhooks

```ts
import { verify } from "@aleph/sdk";

a.webhook("POST /webhooks/stripe", {
  verify: verify.stripe("STRIPE_WEBHOOK_SECRET"),
  dedupe: { bodyField: "id", ttl: "3d" },
})
  .body({ id: t.string().max(64), type: t.string().max(64) })
  .handle(($, { body }) => {
    $.log("stripe event", body.type);
    return { received: true };
  });
```

- **Verification first.** The signature is checked on the exact raw body, in constant time, before the plan runs. A bad, missing, or stale signature returns `401 invalid_signature`.
- **Lenient bodies.** Declare only the fields you use; senders add fields over time, and undeclared ones are ignored.
- **Dedupe.** With `dedupe`, a repeated delivery of the same event id gets the first response replayed, so retries from the sender are harmless.

| Scheme | Use |
|---|---|
| `verify.stripe(secret)` | `Stripe-Signature`, 5-minute tolerance |
| `verify.github(secret)` | `X-Hub-Signature-256` |
| `verify.hmacSha256({ secret, header, prefix?, encoding?, timestampHeader?, tolerance? })` | Any HMAC-SHA256 sender |

In development, pass secrets with `aleph dev --secret STRIPE_WEBHOOK_SECRET=whsec_...`.
