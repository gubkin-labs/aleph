# Async work

Anything that doesn't need to happen inside the request goes through the outbox and runs as its own bounded **job**. Job limits are larger than route limits: 500 reads, 200 writes, 5,000 ops.

## Events

```ts
const OrderPaid = a.event("orderPaid", { payload: { orderId: t.id() } });

OrderPaid.emit({ orderId });                         // in a route or handler, after commit
a.onEvent("receipt", OrderPaid, ($, { payload }) => { /* ... */ });
```

Every handler of an event runs once per emit.

## Entity triggers

```ts
a.onInsert("welcome", User, ($, { payload }) => { /* payload.after is the new row */ });
a.onUpdate("audit", Task, ($, { payload }) => { /* payload.before, payload.after */ });
a.onDelete("cleanup", Project, ($, { payload }) => { /* payload.before */ });
```

## Queues

```ts
const Charge = a.queue("charge", { payload: { orderId: t.id() }, retries: 3, backoff: "2s", maxBackoff: "1m" });

Charge.enqueue({ orderId });                             // now
Charge.enqueue({ orderId }, { delay: "1h" });            // later (at most 30 days)
Charge.enqueue({ orderId }, { delay: "1h", key: orderId });  // keyed: replaces a pending job with this key
Charge.cancel(orderId);                                  // cancels the pending keyed job

a.onQueue("chargeOrder", Charge, ($, { payload, errors }) => { /* ... */ }, { errors: { gone: err.notFound() } });
a.onDeadLetter("chargeFailed", Charge, ($, { payload }) => { /* payload.error, payload.attempts */ });
```

A failed job, whether from a declared error, an integration failure, or a broken invariant, is retried with exponential backoff, then handed to the dead-letter handler.

## Schedules

```ts
a.every("cleanup", "1h", ($, { payload }) => { /* payload.firedAt */ });
a.every("digest", "mon 09:00", ($) => { /* ... */ }, { tz: "Europe/Berlin" });
a.every("standup", "weekdays 08:30", ($) => { /* ... */ }, { tz: "America/New_York" });
a.cron("report", "0 6 1 * *", ($) => { /* 06:00 on the 1st */ }, { tz: "UTC" });
```

Calendar schedules follow the time zone across daylight-saving changes. Missed ticks aren't back-filled: a schedule runs at most once per due time.

## Walking all rows

A job can't scan an unbounded table, but a schedule can walk it in batches:

```ts
a.every("expireTrials", "1d", ($, { payload }) => {
  $.forEach(payload.batch, (org) => {
    $.when(org.trialEndsAt.lt(payload.firedAt), () => org.update({ plan: "free" }));
  });
}, { scan: { entity: Org, index: "byPlan", prefix: ["trial"], batch: 100 } });
```

Each batch is a separately bounded run, chained through the outbox.

## Realtime channels

```ts
const Feed = a.channel("feed", { key: { orgId }, message: { text: t.string().max(200) } });
Feed.publish({ orgId }, { text: "deployed" });
```
